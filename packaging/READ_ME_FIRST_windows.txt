DOCUMENT REDACTOR
=================

Removes confidential information from PDFs while keeping their layout.
Everything happens on your computer. Nothing is uploaded anywhere.


INSTALLING
----------
1. Right-click the zip file you were sent and choose "Extract All...".
   (Don't run the app from inside the zip -- it won't work.)
2. Move the extracted "Document Redactor" folder somewhere permanent,
   for example your Documents folder.
3. Inside it, double-click "Document Redactor.exe".
   Tip: right-click it > "Show more options" > "Send to" > "Desktop (create
   shortcut)" to put it on your desktop.


OPENING IT THE FIRST TIME
-------------------------
The app isn't registered with Microsoft, so the first time you open it
Windows may show a blue box saying "Windows protected your PC".

  1. Click "More info".
  2. Click "Run anyway".

This only happens once.

If the window opens blank, install Microsoft's free "WebView2 Runtime"
(search for "WebView2 Runtime download"). Windows 11 already has it.


USING IT
--------
  1. Drop a PDF on the in-tray (or click it to pick a file).
  2. Mark what to hide: drag across words, or use the AREA tool for
     signatures, photos and logos. BLACKOUT covers with ink; SCRAMBLE swaps
     letters and numbers for random ones so the format stays visible.
     Use "Withdraw page" to remove whole pages.
  3. Click SANITIZE, check the inspection report, then
     "Download sanitized PDF" to save the cleaned copy.

Closing the window erases the document from memory.

Note: this build is for 64-bit Windows 10 and 11.
